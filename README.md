# bedrock-better-redstone
A 16x16 Bedrock resource pack that lets you read the state of your redstone builds at a glance.

Debugging a redstone build usually means staring at identical blocks and guessing which ones are powered. This pack gives each redstone block a clear on/off look, so you can see what your machine is doing without opening menus or breaking blocks. It stays at vanilla 16x16, so everything still looks like Minecraft.

## What changes in game

**Sticky pistons**
- The body and back are mossy stone, so a sticky piston is easy to tell from a normal one.
- The back has a red redstone dot in each corner. These are decoration: textures can't show whether a piston is powered.
- Normal pistons get wooden studs in the back corners.

**Copper bulbs (all 16 variants)**
- A lit bulb is brighter and an unlit bulb is darker, at every oxidation stage.
- A powered bulb shows a large red LED in the center, so you can see when it's about to toggle.

**Redstone dust**
- The wire has a bright core with darker edges. The game still tints dust by signal strength, and this makes the difference between strong and weak dust easier to see.

**Dispensers and droppers**
- Dispensers have a red rim and droppers a gold rim on the faces this pack controls, with a dark outline around the arrows.

**Observers**
- The red glow on a lit observer is stronger, on the back, the top arrow and the side arrow.

**Crafters**
- Idle, triggered and crafting each look distinct, from a dim grid to a bright red crafting grid.

**Repeaters, comparators and redstone lamps**
- An on repeater or comparator has a vivid red bar with a glow, and an off one is dull.
- A lit lamp is brighter and an unlit lamp is darker.

**Hoppers**
- Directional arrows and a glowing red locked state.

## Good to know
- Made for Minecraft Bedrock Edition 1.21.40 or newer.
- Repeater delay and comparator mode can't be changed by a texture pack, so only the on/off look changes.
- If you use other resource packs, put this one above them.
